# Canonical triage labels

| Label | Meaning |
|---|---|
| `needs-triage` | Incoming request requiring classification |
| `needs-info` | Awaiting missing information |
| `ready-for-agent` | Scoped and verified for approved agent implementation |
| `ready-for-human` | Requires a human decision or review |
| `wontfix` | Explicitly not planned, with a concise reason |

Use exactly these strings. Keep one canonical triage role per issue.
