# Issue #15 · QA трёх режимов логотипов

> Historical QA/release snapshot. Current behavior: source code; open work and acceptance: GitHub Issues. Dates and branch status below refer only to this checkpoint.

Дата: 2026-11-16. Ветка: `feat/issue-15-three-logo-modes`. PR: https://github.com/looksawful/ryze-challenge/pull/26.

## Реализованные режимы

1. WebGL: оригинальный morph из старого homework, 3200 частиц.
2. WebGL недоступен, теряет контекст или выдаёт устойчиво низкий FPS: CSS-бегущая строка с пятью логотипами.
3. `prefers-reduced-motion: reduce` или отсутствие JavaScript: все пять исходных логотипов статичны в семантическом HTML.

Набор: Shopify, Google Ads, Meta Ads, TikTok, Google Analytics. Представления Canvas и дубли бегущей строки скрыты от ассистивных технологий.

## Замечания и исправления робо-ревью

- **WebKit:** исходный Shopify AVIF отвечал HTTP 200, но не декодировался (naturalWidth=0); заменён PNG 512×512 с прозрачностью без изменения формы. После изменения WebKit: 4/4 PASS.
- **Opera, software/headless WebGL:** кадры приходили редко, а код зажимал прошедшее время до 0,05 с, из-за чего морфинг почти замирал. Убрано искусственное ограничение времени, добавлена деградация на marquee после трёх последовательных кадров с интервалом более 300 мс. Проверена активная CSS-строка после деградации. Полный повторный прогон: Opera 4/4 PASS.
